ARCHITECTURE AT A GLANCE
========================

Service Worker (background/service-worker.js)
  └─ Orchestrates extension lifecycle
     ├─ Manages debugger attachment per tab
     ├─ Routes 15+ message types
     └─ Syncs rules from storage

Interceptor (background/interceptor.js)
  └─ Listens to Chrome Debugger Protocol
     ├─ Blocks requests matching rules (sends mock response)
     ├─ Captures network logs
     └─ Memory-managed (100 tabs max, 100 logs per tab)

Rule Engine (background/rule-engine.js)
  └─ URL matching and modifications
     ├─ 4 match types (exact, wildcard, regex, contains)
     ├─ 3 modification types (replace, json-path, regex)
     └─ Input validation with error handling

Storage Manager (background/storage-manager.js)
  └─ Persistent local storage
     ├─ Rule/group CRUD operations
     ├─ 10MB quota management
     ├─ Import/export functionality
     └─ Debounced saves (500ms delay)

UI Layers
  ├─ Popup (16KB) - Quick access to rules & network logs
  └─ Options (65KB) - Full rule/group management
