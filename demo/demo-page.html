How to Demo

  1. Click the API Response Interceptor extension icon
  2. Click Attach Debugger to start intercepting
  3. Create a rule with URL pattern: *://jsonplaceholder.typicode.com/*
  4. Set a custom response body or modify specific JSON fields
  5. Click any button above and watch the response change!
