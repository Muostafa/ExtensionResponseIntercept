Help & Documentation

Getting Started

  1. Create a new rule with a URL pattern to match
  2. Choose how you want to modify the response
  3. Click the extension icon and attach the debugger to a tab
  4. Navigate to URLs matching your pattern to see modifications

URL Pattern Examples

*://*/api/* - Matches all API endpoints
https://example.com/* - Matches all URLs on example.com
*/users/* - Matches any URL containing /users/
https://api.example.com/v1/.* - Regex pattern

Modification Types

  • Replace Entire Body: Replace the complete response with your custom content
  • Modify JSON Path: Change specific fields in JSON responses
  • Regex Find & Replace: Use regex to find and replace text patterns
  • Custom Function: Write JavaScript to transform the response

Tips

  • Test your patterns on a single tab first before enabling globally
  • Check the browser console for debugging information
  • The debugger must be attached to a tab for interception to work
  • Be careful with custom functions - they execute with extension privileges
