REQUEST INTERCEPTION SEQUENCE
=============================

1. User clicks extension icon on tab X
   └─ Calls: attachDebuggerToTab(X)

2. Service Worker:
   └─ Attaches debugger via CDP
   └─ Enables Fetch interception
   └─ Adds X to activeTabs

3. User navigates or makes API call on tab X
   └─ Network request triggered

4. REQUEST STAGE (before server):
   
   Request: GET https://api.example.com/users
   
   ├─ SERVICE WORKER receives 'Fetch.requestPaused' event
   │  └─ No responseStatusCode yet
   │
   ├─ RULE ENGINE checks if URL matches any rule
   │  └─ Check: URL pattern match
   │  └─ Check: HTTP method match
   │
   └─ If rule matches:
      ├─ INTERCEPTOR generates mock response
      ├─ INTERCEPTOR applies header modifications
      ├─ INTERCEPTOR applies status code
      └─ Calls: chrome.debugger.sendCommand('Fetch.fulfillRequest')
         └─ Returns mock response immediately
         └─ Server never contacted
         
      If no rule matches:
      └─ Calls: chrome.debugger.sendCommand('Fetch.continueRequest')
         └─ Request continues normally
         └─ Response comes back from server

5. RESPONSE STAGE (after server response):
   
   └─ Only if request was NOT blocked
   │
   ├─ INTERCEPTOR captures response body
   ├─ STORAGE MANAGER logs network request
   └─ Calls: chrome.debugger.sendCommand('Fetch.continueRequest')
      └─ Response returns to page unmodified
      └─ (Can add more stages here in future)

6. Web page receives:
   └─ Mock response (if rule matched) OR
   └─ Actual response (if no rule matched)


MODIFICATION PIPELINE
=====================

Input: Response Body + Rule Configuration
│
├─ TYPE: 'replace'
│  └─ Return: rule.modification.value
│
├─ TYPE: 'json-path'
│  ├─ Parse original body as JSON
│  ├─ Navigate to path (dot notation)
│  ├─ Set new value
│  └─ Return: Stringified JSON
│
├─ TYPE: 'regex'
│  ├─ Parse pattern and flags
│  ├─ new RegExp(pattern, flags)
│  ├─ body.replace(regex, replacement)
│  └─ Return: Modified string
│
└─ Output: Modified Response Body


RULE STRUCTURE
==============

{
  id: 'rule_uuid',                    // Unique identifier
  name: 'Mock API',                   // User-defined name
  description: 'Optional',            // Optional description
  enabled: true,                      // Enable/disable
  groupId: 'group_uuid',              // Optional group
  
  // URL MATCHING
  urlPattern: '*://api.example.com/*',
  matchType: 'wildcard',              // exact|wildcard|regex|contains
  
  // METHOD FILTERING
  methods: ['GET', 'POST'],           // HTTP methods
  
  // BODY MODIFICATIONS
  modifyType: 'replace',              // replace|json-path|regex
  modification: {
    type: 'json',
    value: '{"status": "ok"}'         // Depends on modifyType
  },
  
  // HEADER MODIFICATIONS
  modifyHeaders: [
    { action: 'set', name: 'CORS', value: '*' },
    { action: 'remove', name: 'X-Frame-Options' }
  ],
  
  // STATUS CODE
  modifyStatusCode: 200,              // Override status
  
  // METADATA
  createdAt: 1234567890,
  modifiedAt: 1234567890
}

SECURITY BOUNDARIES
===================

Content Scripts: NONE
└─ Extension runs in service worker only
└─ No injected code into pages
└─ Safer, more secure approach

Data Flow: Debugger Protocol ↔ Storage
└─ No external network calls
└─ All data stays local
└─ User-generated rules only

Code Execution:
└─ HTML escaping on all user data
└─ No eval() or Function()
└─ No arbitrary JavaScript execution
└─ Regex errors caught and skipped

Permissions:
└─ debugger - Necessary for core feature
└─ storage - Local data persistence
└─ activeTab - User-initiated
└─ tabs - Session tracking
└─ <all_urls> - Required for dev tool


MEMORY MANAGEMENT
==================

per Tab:
└─ Network logs: Max 100
└─ Storage: ~50KB (truncated)

Global:
└─ Active tabs: Max 100
└─ Cleanup every 5 minutes

Storage Limits:
└─ Max: 10MB (Chrome limit)
└─ Warning at 80% usage
└─ Saves blocked if over limit


RUNTIME FLOW (High Level)
==========================

Extension Load
├─ Manifest parsed
├─ Service worker started
├─ Rules loaded from storage
├─ Storage listeners registered
└─ Ready for user interaction

User clicks extension icon
├─ Popup displayed
├─ Status checked
├─ Rules listed
└─ Network logs shown

User clicks "Attach Debugger"
├─ Message sent to service worker
├─ chrome.debugger.attach() called
├─ Fetch.enable configured
├─ Tab added to activeTabs
└─ Ready for interception

User navigates web page
├─ All network requests intercepted
├─ Rules evaluated per request
├─ Requests blocked or continued
├─ Responses logged
└─ Page receives final response

User creates rule
├─ Rule validated
├─ Saved to chrome.storage.local
├─ Debounced save (500ms)
├─ Listeners notified
├─ Rule engine updated
└─ Effective immediately

Periodic Cleanup (every 5 minutes)
├─ Check if tabs still exist
├─ Remove stale tabs
├─ Enforce tab limit
└─ Log summary
